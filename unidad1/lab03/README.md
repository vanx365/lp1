# Explicacion Codigo    
## while
- ¿Qué hace? Ejecuta el código mientras la condición sea verdadera. Primero revisa la condición, luego ejecuta. Si la condición es falsa desde el inicio, no se ejecuta ni una vez.
## Do While
- ¿Qué hace? Ejecuta primero el código y luego revisa la condición. Siempre se ejecuta al menos una vez, aunque la condición sea falsa desde el inicio.
## Continue
- ¿Qué hace? Se salta la iteración actual y pasa directo a la siguiente vuelta del bucle. No sale del bucle, solo se salta lo que queda de esa repetición.
## Break 
- ¿Qué hace? Termina el bucle completamente y de inmediato. Sale del bucle y no continúa con las iteraciones restantes.
